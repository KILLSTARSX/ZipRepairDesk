KILL-STAR SX 根证书
==================

这个证书用来让 Windows 认出 KILL-STAR SX 发布的软件，
避免每次运行都显示“未知发布者”。

同一套根证书可以签所有 KILL-STAR SX 桌面软件，
换软件不用换证书；每台电脑、每个 Windows 用户装一次即可。


安装（Windows 10 / 11）
-----------------------

1. 双击 KILL-STAR SX Root CA.cer。
2. 点“安装证书”。
3. 选择“当前用户”，点“下一步”。
4. 选“将所有的证书都放入下列存储”，点“浏览”，
   选择“受信任的根证书颁发机构”，确定，下一步，完成。
5. 如果弹出安全警告，确认颁发者是
   “KILL-STAR SX Root CA”，点“是”。


验证
----

右键 ZipRepairDesk.exe → 属性 → 数字签名，
能看到“KILL-STAR SX”且状态有效即可。


卸载
----

Win + R 输入 certmgr.msc，
打开“受信任的根证书颁发机构 → 证书”，
找到“KILL-STAR SX Root CA”删除。


注意
----

- 证书只包含公钥，不含私钥，也不会联网。
- 只从官方仓库或发布页下载，不要安装来源不明的根证书。
- 安装证书只减少“未知发布者”提示，不能保证杀毒软件不误报。
